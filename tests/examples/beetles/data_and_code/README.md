# Beetle heat survival

## Authors
A. Author (a.author@example.edu)

## Summary
Survival of dung beetles in a heat-stress experiment.

## Files
- `data/beetles.csv`: one row per beetle. `beetle_id` (ID), `site` (N or S), `treatment` (control or heat), `mass_mg` (body mass, mg), `survived` (1 = alive at day 14).
- `code/01_analysis.py`: Table 1, Figure 2, and the survival difference.
- `outputs/`: results written by the code.

## Running
From this folder: `python code/01_analysis.py`
